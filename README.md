# 3D Landing Page - Interactive Honey Jar

A fully interactive single-page web application featuring a beautiful 3D honey jar that users can explore and customize.

## Features

### Core Feature: Interactive 3D Honey Jar 🍯
- Fully interactive 3D model built with CSS 3D transforms
- Drag to rotate the honey jar in any direction
- Smooth animations with beautiful gradients and shadows
- Touch-enabled for mobile devices
- Gentle floating animation when idle

### Unlockable Features (Activated by Interaction)

Once you interact with the honey jar, two additional features become available:

1. **Interaction Counter 📊**
   - Tracks the total number of interactions with the 3D model
   - Real-time counter updates as you interact
   - Visual feedback for user engagement

2. **Honey Color Picker 🎨**
   - Change the color of the honey inside the jar
   - Full color spectrum selection
   - Instant visual updates to the 3D model

## How to Use

1. Open `index.html` in a modern web browser
2. Drag your mouse (or use touch on mobile) to rotate the honey jar
3. Watch as the features panel unlocks after your first interaction
4. Use the color picker to customize the honey color
5. See your interaction count increase with each movement

## Technical Details

- **No build process required** - Just open the HTML file!
- Uses CSS 3D transforms for hardware-accelerated 3D rendering
- Pure vanilla JavaScript - no frameworks or external libraries
- Fully responsive design
- Mobile-friendly with touch support

## Browser Compatibility

Works best in modern browsers that support:
- WebGL
- ES6 JavaScript
- CSS3 transforms and animations

Recommended browsers:
- Chrome 90+
- Firefox 88+
- Safari 14+
- Edge 90+
